# คู่มือเขียนบทความให้ติด Google (สำหรับทีม ECOMACROBIZ)

คู่มือนี้อธิบายวิธีใช้เครื่องมือ SEO ในหลังบ้าน (`/admin`) ให้บทความมีโอกาสติดอันดับ Google มากที่สุด
ระบบจะ "แนะนำ" เสมอ แต่ไม่เคยบล็อกการเผยแพร่ — การตัดสินใจสุดท้ายเป็นของผู้เขียน

---

## 1. ก่อนเริ่มเขียน: เลือก "คีย์เวิร์ดหลัก" (Focus keyword)

- 1 บทความ = 1 คีย์เวิร์ดหลัก คือคำที่ลูกค้าพิมพ์ค้นหาจริง เช่น `การสร้างแบรนด์ B2B`, `branding คืออะไร`
- อย่าใช้คีย์เวิร์ดเดียวกันกับบทความอื่นของเรา (บทความจะแย่งอันดับกันเอง)
- ใส่ในช่อง **คีย์เวิร์ดหลัก** ในแผง SEO ด้านขวาของหน้าแก้ไขบทความ แล้วคะแนน SEO จะคำนวณใหม่ทันที

## 2. อ่านคะแนน SEO และเช็กลิสต์

แผง SEO แสดงคะแนน 0–100 พร้อมรายการตรวจ แต่ละข้อเป็น ✓ ผ่าน / ! ควรปรับ / ✕ ยังไม่ผ่าน และมีคำแนะนำวิธีแก้

| ข้อตรวจ | ทำอย่างไรให้ผ่าน |
| --- | --- |
| คีย์เวิร์ดอยู่ใน SEO title | ใส่คีย์เวิร์ดไว้ต้น ๆ ของหัวข้อ |
| คีย์เวิร์ดอยู่ใน slug (URL) | slug เป็นภาษาอังกฤษตัวเล็ก คั่นด้วย `-` เช่น `b2b-branding-guide` (คีย์เวิร์ดภาษาไทย ระบบจะเตือนให้ตรวจเอง) |
| คีย์เวิร์ดอยู่ในย่อหน้าแรก | เปิดบทความด้วยประโยคที่มีคีย์เวิร์ด ตอบคำถามผู้อ่านทันที |
| มีหัวข้อ H2 อย่างน้อย 1 ข้อ และมีคีย์เวิร์ด | แบ่งเนื้อหาด้วยหัวข้อ (พิมพ์ `/` แล้วเลือก "หัวข้อ 2") |
| ความยาว SEO title | ระบบวัดเป็น "ความกว้างพิกเซล" แบบที่ Google ตัด เว็บจะต่อท้าย " \| ECOMACROBIZ" ให้อัตโนมัติ จึงควรเขียนประมาณ 35–46 ตัวอักษร |
| ความยาว meta description | 120–160 ตัวอักษร สรุปประโยชน์ที่ผู้อ่านจะได้ + มีคีย์เวิร์ด |
| H1 มีแค่ 1 อัน | ชื่อบทความคือ H1 อยู่แล้ว ห้ามใช้ H1 ในเนื้อหา |
| ลำดับหัวข้อไม่ข้ามขั้น | H2 → H3 → H4 ห้ามข้ามจาก H2 ไป H4 |
| รูปทุกรูปมี alt ภาษาไทย | อธิบายว่าในรูปคืออะไร เช่น "ทีมงานกำลังวางแผนอัตลักษณ์แบรนด์" (ไม่ใช่ "รูปที่ 1") |
| ลิงก์ภายในอย่างน้อย 2 ลิงก์ | ใช้ "ลิงก์แนะนำ" ในแผง SEO แล้วกด **แทรก** — ระบบเลือกบทความที่หมวดหรือคำใกล้เคียงกันให้ |
| ลิงก์ภายนอก | ลิงก์ไปแหล่งอ้างอิงที่น่าเชื่อถือเท่านั้น (https) เว็บใส่ `rel="noopener noreferrer"` และเปิดแท็บใหม่ให้อัตโนมัติ |
| จำนวนคำ / เวลาอ่าน | บทความความรู้ควรยาวพอจะตอบคำถามครบ (โดยทั่วไป 800 คำขึ้นไป) |
| มีรูปปก + alt รูปปก | รูปปกใช้แสดงบน Google, Facebook, LINE |

คะแนนไม่จำเป็นต้องได้ 100 — ให้ความสำคัญกับ "เนื้อหาตอบคำถามผู้อ่านได้ดีที่สุด" ก่อนเสมอ

## 3. ตัวอย่างการแสดงผล

- **Google preview** (เดสก์ท็อป/มือถือ): ดูว่าหัวข้อและคำอธิบายถูกตัดหรือไม่
- **Facebook / LINE / X preview**: ใช้ภาพแชร์ (OG image) จริง — ลำดับคือ ภาพแชร์ที่ตั้งเอง → รูปปก → ภาพอัตโนมัติ
  (ระบบสร้างภาพพร้อมชื่อบทความภาษาไทยให้เองถ้าไม่มีรูป)

## 4. ช่องตั้งค่า SEO ขั้นสูง

| ช่อง | ใช้เมื่อไร |
| --- | --- |
| **Canonical URL** | ปล่อยว่างเกือบทุกกรณี ใช้เฉพาะเมื่อเนื้อหานี้คัดลอกมาจากหน้าอื่นที่เป็นต้นฉบับ (ต้องเป็น https) บทความที่ชี้ canonical ไปที่อื่นจะไม่อยู่ใน sitemap |
| **ไม่ให้ Google เก็บ (noindex)** | หน้าชั่วคราว, โปรโมชันหมดอายุ, เนื้อหาซ้ำ บทความยังเปิดได้และอยู่ในหน้า Knowledge แต่ Google จะไม่แสดงในผลค้นหา และไม่อยู่ใน sitemap |
| **ภาพแชร์ (OG image) + alt** | อยากให้ภาพตอนแชร์ต่างจากรูปปก ขนาดแนะนำ 1200×630 |

## 5. URL เปลี่ยน / ยกเลิกเผยแพร่ / ลบ — ระบบดูแลให้

- **เปลี่ยน slug ของบทความที่เผยแพร่แล้ว**: URL เดิมจะ redirect แบบ 301 ไป URL ใหม่โดยอัตโนมัติ (คะแนน SEO ไม่หาย)
  แต่ควรเปลี่ยนให้น้อยที่สุด
- **ยกเลิกเผยแพร่หรือลบ**: ระบบจะถามว่าจะส่งผู้เข้าชมไปที่ไหน
  - เลือกบทความใกล้เคียง หรือหน้า /knowledge → 301 (แนะนำถ้ามีเนื้อหาทดแทน)
  - หรือ "ลบถาวร (410)" → บอก Google ให้นำหน้าออกจากผลค้นหาเร็วขึ้น
- **เผยแพร่ใหม่** ที่ URL เดิม → redirect/410 ของ URL นั้นถูกลบออกให้อัตโนมัติ
- หน้า **เปลี่ยนเส้นทาง URL** (`/admin/redirects`, owner/บรรณาธิการ) ใช้ดู/เพิ่ม/แก้ redirect เอง
  ระบบไม่ยอมให้ทำ redirect วน (loop) หรือต่อกันหลายทอด (chain) และห้าม redirect หน้าหลักของเว็บ
- ทุกครั้งที่เผยแพร่/แก้ไข หน้า Knowledge, หมวดหมู่, หน้าแรก, sitemap.xml และ RSS อัปเดตทันที

## 6. การตั้งเวลาเผยแพร่

เลือก "ตั้งเวลา" แล้วกำหนดวันเวลา (เวลาไทย) ระบบจะเผยแพร่เองภายใน ~1 นาทีหลังเวลาที่ตั้ง
และแจ้ง Bing/Yandex ผ่าน IndexNow ถ้าเปิดใช้ (Google ไม่มีระบบ ping — ใช้ sitemap แทน)

## 7. รูปภาพ

- อัปโหลดรูปขนาดใหญ่ได้ ระบบลดขนาดเหลือด้านยาวสุด 2560px หมุนรูปให้ถูก และลบข้อมูล EXIF/GPS ออกให้อัตโนมัติ
- ชื่อไฟล์บนเว็บสร้างจาก alt/ชื่อไฟล์ภาษาอังกฤษ — ตั้งชื่อไฟล์ให้สื่อความหมายก่อนอัปโหลด เช่น `brand-workshop.jpg`
- ใส่ alt ภาษาไทยทุกรูป (คลังสื่อแก้ alt ได้ภายหลัง)
- เว็บแปลงเป็น WebP/AVIF และกำหนดขนาดรูปให้เอง จึงไม่เกิดการกระตุกของหน้า (CLS)

## 8. หลังย้ายโดเมนมาเว็บใหม่ (Search Console)

1. เข้า Google Search Console ด้วยบัญชีที่ยืนยันโดเมน `ecomacrobiz.com` ไว้ (มี TXT ยืนยันอยู่แล้ว)
   ถ้าไม่มี ให้เพิ่ม **Domain property** แล้วยืนยันด้วย TXT record ใน Cloudflare
2. **Sitemaps** → ส่ง `https://www.ecomacrobiz.com/sitemap.xml`
3. **URL Inspection** → ทดสอบหน้าแรกและบทความ 2–3 หน้า → "Request indexing"
4. ทุกสัปดาห์ช่วง 4 สัปดาห์แรก: ดูรายงาน **Pages** (Not found 404, Redirect, Crawled – currently not indexed)
   ถ้าเจอ URL เก่าจาก Wix ที่ 404 ให้เพิ่ม redirect ที่ `/admin/redirects`
5. (ไม่บังคับ) Bing Webmaster Tools → นำเข้าจาก Search Console แล้วเปิด IndexNow (ตั้ง `INDEXNOW_KEY`)

## 10. เช็กลิสต์สั้นก่อนกด "เผยแพร่"
